# How To Install IPFS Locally

IPFS Desktop is the easiest way to run a local IPFS node with a graphical interface. Pick the guide for your operating system:

* [IPFS Desktop (Windows)](ipfs-desktop-windows.md)
* [IPFS Desktop (Linux)](ipfs-desktop-linux.md)
* [IPFS Desktop (Mac)](ipfs-desktop-mac.md)

Prefer the command line, or planning to keep a node running long-term? See [Running Your Own IPFS Node and IPNS Publishing](../../intermediate/running-your-own-ipfs-node.md) for a Kubo-based setup.
