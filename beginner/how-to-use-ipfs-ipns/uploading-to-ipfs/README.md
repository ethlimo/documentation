# Uploading to IPFS

There are two ways to get your dWebsite content onto IPFS and keep it available:

* [Self-Hosting Instructions for IPFS and IPNS](self-hosting-instructions-for-ipfs-and-ipns.md) — upload and pin from your own machine using IPFS Desktop
* [Hosting using a pinning service](hosting-using-a-pinning-service.md) — let a pinning service keep your content online for you

Not sure why pinning matters? See [What is IPFS Pinning?](../../../ipfs/what-is-ipfs-pinning.md)
